## 项目介绍

### 简介

该项目是**FOR-YOURSELF**项目生态后端的主项目，主要包含公共模块，网关模块以及账号管理模块。  
该项目目前仅用于**学习**、**展示**、**毕设**以及**大型生态项目的Demo**，近一年内不会维护和更新。
